## 0. 閱讀指引

1. **優先級定義**
   - **P0 必做**：缺少此項，遊戲無法達成專題基本要求，或 rubric 會跌到 2 分以下。
   - **P1 應做**：把 rubric 由「做到」推到 3–4 分的關鍵，亦是與其他組作品拉開差距的地方。
   - **P2 加分**：時間容許才做，主要提升體驗與展示效果，不影響化學評分。
2. **每條需求皆附驗收條件**，可逐項打勾，方便分工與自我檢查。
3. **「對應」欄**指向遊戲 rubric 的五項準則：
   - **R1** 鍵結概念與分類準確度（20%）
   - **R2** 點叉圖與電子計算（20%）
   - **R3** 迷思概念辨識與糾正（20%）
   - **R4** 覆蓋範圍、進度與課綱對齊（20%）
   - **R5** 供同伴學習的學習設計（20%）
4. 本文件只寫「要做什麼」與「怎樣算做完」，不規定實作方式；現有程式碼 (`index.html` / `_src/`) 可繼續沿用。

## 1. 產品定位與設計原則

### 1.1 定位

| 問題 | 回答 |
|---|---|
| 這是什麼？ | 一個 6–10 分鐘可通關的 3D 開放世界化學鍵溫習遊戲，供中四學生（F4）獨立使用 |
| 給誰玩？ | 主要：同級另一班同學（peer-use session）；次要：自己溫習、老師課堂示範 |
| 玩完要得到什麼？ | 能分類陌生化合物的鍵型、能畫出正確點叉圖、能解釋至少 3 個常見誤解、拿到一份個人弱點總結 |
| 不是什麼？ | 不是編程比賽、不是打怪遊戲、不是《原神》的換皮；沒有抽卡、沒有付費、沒有隨機獎勵驅動 |

### 1.2 五條不可妥協的原則

1. **化學正確優先於遊戲爽度。** 任何機制只要會製造新誤解，就砍掉。所有「技能」「敵人」「道具」都必須對應真實化學性質，不得憑空發明反應。
2. **這不是編程比賽。** 畫面華麗與程式複雜度不計分；計分的是「能否教懂另一個人」。功能取捨時，永遠選「更有教學效果」而非「更炫」。
3. **單次體驗 6–10 分鐘。** 主線必須能在 10 分鐘內完成；支線與收集留給回訪。任何單一關卡不得超過 90 秒。
4. **一個檔案、離線可跑、另一班即開即用。** 不依賴網絡、不依賴安裝、不收集個人資料；換機雙擊即玩。
5. **每個錯誤都要解釋「為什麼錯」。** 只講「錯」或「正確答案是 B」一律視為未完成（直接對應 R3 與 R5）。

### 1.3 與評分準則的對應

| Rubric | 本作對應系統 | 主要章節 |
|---|---|---|
| R1 概念與分類 | 三步分類引擎、結構解析戰、詞彙表 | 4.4 / 4.10 |
| R2 點叉圖與電子計算 | 點叉盤（互動繪製）、電子對計數器 | 4.5 |
| R3 迷思辨識與糾正 | 誤解型干扰項、解釋性回饋、迷思診所 | 4.4 / 4.9 |
| R4 覆蓋、進度、課綱 | 四區分級題庫、由淺入深解鎖、巨型結構對比 | 4.3 / 5 |
| R5 同伴學習設計 | 任務面板、提示分級、溫習總結、6–10 分鐘節奏、pilot 記錄 | 4.6 / 4.11 |

| 名詞 | 英文 | 定義 | 對應真實化學 |
|---|---|---|---|
| 鍵性 | bond affinity | 角色與題目所屬的鍵結類別：離子性／共價性／金屬性 | 離子鍵、共價鍵、金屬鍵 |
| 鍵師 | bond keeper | 玩家可切換的三位角色統稱 | — |
| 結構體 | structure entity | 世界中的「對手」，其實是一個待解析的結構 | 離子晶格、巨型共價結構、金屬晶格、簡單分子 |
| 解析 | analysis | 取代「攻擊」：用正確的化學條件削弱結構穩定度 | 溶解、加熱、電子海、分子間力 |
| 穩定度 | lattice stability | 取代「生命值」的進度條；降到 0 即結構被正確解釋 | 晶格能／鍵強度概念 |
| 電子對 | electron pair | 點叉圖中共用或孤立的兩粒電子 | bond pair / lone pair |

| 共鳴 | resonance | 連續答對形成的連段獎勵（不涉及化學「共振」概念，介面須避免混淆，建議改稱「連段」） | — |
| 研究筆記 | research note | 角色裝備，提供被動提示 | — |

> **命名注意**：介面上避免使用「元素」「命座」「聖遺物」「深淵」等與其他作品直接關聯的詞；「共鳴」一詞因與化學共振（resonance）撞名，**介面統一改稱「連段 Combo」**。

## 3. 核心遊玩循環

```
探索（行走／觀察） → 遭遇（NPC／結構體／寶箱／晶體）
      ↓
判定（三步分類 或 點叉圖 或 結構解析）
      ↓
回饋（為什麼對／為什麼錯，指向具體規則）
      ↓
記錄（答題、用時、弱點）→ 解鎖（新區域、新題型、傳送點、筆記）
      ↓
回到探索（帶著新知識）
```

**設計約束**：任何一輪循環必須在 60–90 秒內閉合；玩家永遠知道「我下一步要做什麼」（任務面板 + 世界標記 + 小地圖三重指示）。

## 4. 系統需求

### 4.1 開放世界探索（FR-EX）

**目標**：提供「自由行走 → 自然遇到題目」的探索感，同時確保不會迷路、不會跳過必修內容。

| 編號 | 需求 | 優先級 | 驗收條件 | 對應 |
|---|---|---|---|---|
| FR-EX-01 | 提供一張無縫連續的 3D 大地圖，劃分四個主題區：離子平原、共價森林、金屬山脈、晶體洞窟 | P0 | 玩家由出生點可步行到四區，途中無載入畫面；區界以地形色彩與霧自然過渡 | R4 |
| FR-EX-02 | 角色以 WASD 移動、空白鍵跳躍、滑鼠鎖定轉視角；第三人稱跟隨 | P0 | 不出現卡地形、穿地、視角翻轉；連續移動 30 秒無明顯掉幀 | R5 |
| FR-EX-03 | 每區有明確地標（公會、商店、傳送錨點、巨型結構），讓玩家用視覺定位 | P1 | 站在出生點可辨認至少兩個地標；地標有 3D 標記或招牌 | R4 |
| FR-EX-04 | 世界物件（樹、石、晶體、草）不得遮擋任務點、傳送點或生成在玩家出生位置 | P0 | 任何任務點半徑 8 米內無大型物件；出生點 16 米內無碰撞體 | R5 |
| FR-EX-05 | 提供小地圖（常駐）與大地圖（可開關），顯示玩家位置、朝向、任務點、傳送點 | P0 | 小地圖有玩家箭頭、目標虛線與方位 N；大地圖可縮放拖曳 | R5 |
| FR-EX-06 | 探索行為需被記錄（去過哪區、停留時間、行走距離），作為 pilot 證據 | P1 | 匯出檔含 `zonesVisited`、`timePerZone`、`distanceTraveled` | R5 |
| FR-EX-07 | 支援低效能裝置的降級：關閉陰影、降低粒子密度、降低解析度 | P2 | 設定可切換「效能優先」模式，幀率提升可感知 | R5 |

**設計取捨**：不做日夜循環、天氣、攀爬、游泳。這些只增加開發量，對「教懂化學」零貢獻。

### 4.2 角色切換與隊伍搭配（FR-PT）

**目標**：把「三種鍵」變成三個可操作角色，讓玩家在切換之間體會三者的差異；但**不能因為搭配而令某種鍵永遠沒機會練**。

| 編號 | 需求 | 優先級 | 驗收條件 | 對應 |
|---|---|---|---|---|
| FR-PT-01 | 隊伍固定三人：離子使（Ion Keeper）、共價師（Bond Weaver）、金屬行者（Lattice Walker） | P1 | 三人恆在隊伍，任何時候都能切換，不存在「缺少某角色而無法完成內容」 | R4 |
| FR-PT-02 | 按 1／2／3 或點擊頭像即時切換，切換有 0.3 秒過場與角色台詞 | P1 | 切換延遲 < 0.3 秒；切換時鎖定移動輸入 | R5 |
| FR-PT-03 | 每位鍵師有一個被動提示，只在對應題型生效：離子使→電荷與方括號；共價師→孤對與鍵對；金屬行者→離域電子 | P1 | 被動只提示「看哪裡」，不直接給答案 | R3 / R5 |
| FR-PT-04 | 每位鍵師有一個「解析工具」，只對正確結構類型有效（見 FR-CB-03） | P1 | 用錯工具時，系統解釋「為何這個條件不適用」，而非只顯示無效 | R1 / R3 |
| FR-PT-05 | 隊伍可調整「出戰順序」，決定快捷鍵 1/2/3 的分配 | P2 | 設定後即時生效並保存 | R5 |
| FR-PT-06 | 每位鍵師可裝備 1 件「研究筆記」，提供一種被動（例：點叉盤顯示電子總數提示） | P2 | 同一時間只能裝 1 件；效果在 HUD 有圖示 | R5 |
| FR-PT-07 | 角色外觀須原創，不得使用任何現有作品的角色、服裝、配色組合或名稱 | P0 | 美術與命名可溯源至自製或已授權素材，並在 AI-use log 註明 | — |

**設計取捨**：不做抽卡、不做角色稀有度、不做「戰力數值」。三名鍵師只是三種「思考方式」的具象化，強度完全相等。

### 4.3 鍵性互動「結構解析」戰（FR-CB）

**目標**：用「戰鬥」的外殼包裝「判斷結構類型 → 應用正確化學條件」的解題流程。**沒有死亡、沒有失敗懲罰、沒有隨機暴擊。**

| 編號 | 需求 | 優先級 | 驗收條件 | 對應 |
|---|---|---|---|---|
| FR-CB-01 | 結構體分四類：離子晶格、巨型共價結構、金屬晶格、簡單分子；外觀與所屬區對應 | P1 | 四類外觀可區分；同一結構在場上不重複出現超過 2 個 | R1 / R4 |
| FR-CB-02 | 每場解析戰 3 回合：① 判斷結構類型 → ② 選正確的破解條件 → ③ 解釋一句理由 | P1 | 三回合合計 45–70 秒；每回合都有獨立回饋 | R1 / R3 |
| FR-CB-03 | 破解條件必須化學正確，且與結構一一對應（見下表） | P0 | 任何錯誤配對都能給出「為什麼不適用」的解釋 | R1 |
| FR-CB-04 | 穩定度條（取代血條）只下降、不歸零失敗；答錯會停頓並顯示解釋，容許重試 | P1 | 答錯 3 次後自動提供「提示 → 示範」兩級協助 | R5 |
| FR-CB-05 | 連段（Combo）：連續 3 回合正確顯示「3 連段」，只加熟悉度，不加數值攻擊力 | P2 | 連段中斷不清空已得分 | R5 |
| FR-CB-06 | 戰鬥中不得出現與化學無關的數值膨脹（暴擊、屬性抗性、等級壓制） | P0 | 代碼與 UI 均無此類數值 | — |
| FR-CB-07 | 每場戰鬥結束顯示「本場用到哪條規則」的一句話總結 | P1 | 總結可直接對應課堂筆記的規則編號 | R3 / R4 |

**破解條件的化學對應（必須遵守）**

| 結構類型 | 正確條件 | 化學依據 | 常見錯誤配對與回饋重點 |
|---|---|---|---|
| 離子晶格（NaCl、MgO） | 加水／加熱至熔融 | 離子鍵由靜電吸引維持；水合或熔融後離子可移動，故導電 | 用「分子間力」無效：離子晶格不是分子，沒有獨立分子可言 |
| 巨型共價結構（鑽石、石墨） | 極高能量（高溫）或沿層滑移（石墨） | 大量共價鍵形成三維網狀／層狀；熔點極高、不溶於水 | 用「加水」無效：共價鍵不會被水拆開；石墨層間有離域電子可導電 |
| 金屬晶格（Fe、Cu） | 電子海調諧（通電／施加形變） | 離域電子可自由移動，故導電、有延展性 | 用「加水」無效：金屬不會溶解成離子；亦不可說「金屬鍵是電子轉移」 |
| 簡單分子（H₂O、CO₂） | 克服分子間力（低溫即可） | 分子內是共價鍵，分子間只有微弱作用力，故熔沸點低 | 說「分子間是共價鍵」是錯的；說「CO₂ 導電」是錯的 |

> **紅線**：不得為了好玩而加入「鍵能炮」「電子束」等聽起來像科學但無對應概念的技能名稱。技能名稱必須是課本用語（水合、熔融、電子海、分子間力）。

### 4.6 角色養成（FR-PG）

**目標**：把「溫習進度」偽裝成「角色成長」，令學生願意重複練習；但成長只解鎖**輔助**，不解鎖**內容**。

## 5. 內容規格

### 5.1 化合物分級（依現有題庫整理）

| 級別 | 區域 | 化合物例子 | 教學意圖 |
|---|---|---|---|
| T1 入門 | 離子平原／出生點 | NaCl、H₂、Fe | 三種鍵各一，建立最基本分類 |
| T2 中階 | 共價森林／金屬山脈 | H₂O、CO₂、MgCl₂、Cu、HCl | 加入多原子、離子電荷、金屬延展性 |
| T3 高階 | 晶體洞窟 | Mg₃N₂、NH₄Cl、BF₃、鑽石、石墨、C₆₀ | 陌生化學式、巨型結構、例外與爭議點 |

### 5.2 點叉圖題目（8 題）

NaCl、MgO、HCl、H₂O、CH₄、NH₃、CO₂、N₂。每題需標明：原子數、最外層電子數、鍵對數、孤對數、是否需要方括號與電荷。

### 5.3 六個常見誤解（干擾項設計）

| # | 誤解說法 | 為什麼錯 | 回饋要點 |
|---|---|---|---|
| M1 | 「NaCl 是一個分子」 | 它是巨型離子晶格，沒有獨立分子 | 強調「晶格」與「分子」差別 |
| M2 | 「金屬鍵是電子轉移」 | 金屬是離域電子海，不是轉移給特定原子 | 用「電子海」圖示糾正 |
| M3 | 「CO₂ 可以導電」 | 簡單分子、無自由離子或電子 | 對比石墨（有離域電子） |
| M4 | 「O₂ 是單鍵」 | 氧是雙鍵（O=O） | 用電子數計算證明 |
| M5 | 「NH₃ 的孤對也拿去共用」 | 孤對不參與成鍵，造成角錐形 | 用鍵對／孤對數目核對 |
| M6 | 「BF₃ 滿足八隅體」 | 硼只有 6 粒電子，屬例外 | 說明「八隅體規則有例外」 |

### 5.4 詞彙表（至少 8 條）

ionic bond、covalent bond、metallic bond、delocalised electron、lone pair、bond pair、giant ionic lattice、giant covalent structure、simple molecule、electrostatic attraction、octet rule。

## 7. 預期玩家流程

### 7.1 首次遊玩（目標 8 分鐘）

| 時間 | 階段 | 玩家在做什麼 | 系統在做什麼 |
|---|---|---|---|
| 0:00–0:30 | 開場 | 讀 3 句故事、看 5 步說明、按開始 | 顯示目標與控制鍵；鎖定滑鼠 |
| 0:30–1:00 | 引導 | 跟箭頭走向第一個 NPC | 5 步聚光燈引導；任務面板顯示距離與方位 |
| 1:00–2:30 | 第一題 | 答 NaCl 三步分類（組成→電子行為→鍵型） | 每步即時回饋；答錯給解释；完成 +1 |
| 2:30–3:30 | 第一幅點叉圖 | 開寶箱，畫 NaCl 點叉圖 | 工具列、做法提示、逐項檢查 |
| 3:30–4:30 | 探索 | 走向共價森林，順手採集晶體、解鎖傳送錨點 | 區名提示、錨點啟動動畫、詞彙解鎖 |
| 4:30–6:00 | 第二／三題 | H₂、Fe、H₂O，開始遇到陌生化合物 | 軟性解鎖提示；地圖可傳送回起點 |
| 6:00–7:20 | 解析戰（M2 後） | 3 回合判斷結構與破解條件 | 穩定度條、每回合解釋、連段 |
| 7:20–8:00 | 收尾 | 看溫習總結、匯出數據 | 三種鍵正確率、弱點建議、pilot 記錄 |

**節奏檢查點**：3 分鐘內必須已完成至少 1 題 + 1 幅圖；否則考慮縮短步行距離或提高移動速度。

### 7.2 回訪流程（3–5 分鐘）

1. 由傳送錨點直達未完成區域。
2. 任務清單挑一項支線或弱點題型。
3. 完成後看熟悉度是否升級。
4. 可選擇重玩解析戰或補完詞彙。

### 7.3 另一班試玩流程（peer-use session）

1. 老師或組員用 30 秒介紹目標（不示範操作）。
2. 同學獨立遊玩 8 分鐘，組員只觀察、不指導。
3. 填寫 3 題前測 → 遊玩 → 3 題後測。
4. 組員記錄：卡在哪一步、哪句回饋看不懂、有沒有說出錯誤概念。
5. 依觀察修改 1–2 個最常見的卡點，再測一次（pilot 迭代）。

## 11. 風險與取捨

| 風險 | 影響 | 對策 |
|---|---|---|
| 為做戰鬥而犧牲化學正確 | R1/R3 直接扣分 | 所有技能名稱與效果先過「課本用語檢查」；不能對應真實性質的機制一律刪 |
| 三位角色令內容覆蓋失衡 | R4 扣分 | 三人恆在隊伍，任何角色都能完成所有題型；角色只改變提示方式 |
| 養成變成練等 | 6–10 分鐘目標失守 | 熟悉度只解鎖輔助，不解鎖內容；上限 5 級 |
| 探索太大导致迷路 | 玩家放棄 | 任務面板三重指示 + 傳送錨點 + 地標；必要時縮小世界半徑 |
| 加入太多系統做不完 | 交付風險 | 嚴守 M1 優先；M2 可整段砍掉 |
| 依賴 AI 生成內容出錯 | 化學錯誤 | 每個 AI 產出都要對照課本核實，並記入 AI-use log |
