## 0. 診斷：為什麼現在「垃圾」

不是「畫得不夠多」，是四件事同時出錯。按影響排序：

| # | 問題 | 證據 | 影響 |
|---|---|---|---|
| **1** | **材質色被當成線性值再 sRGB 編碼一次 → 全員抬亮約 1.9 倍、飽和度掉一半** | `coat = 0x2f5f96`（深藍），實拍上屏 ≈ `#a9cdd8`（粉藍）。`renderer.outputEncoding = sRGBEncoding` + r128 不轉換輸入色 | 最大問題。所有顏色糊成一團粉彩，明度層級全失，賽璐璐的分段看不出來 |
| **2** | **軀幹 y 座標與動畫打架** | `torso` 建在 `y=2.03`，但 walk 分支每帧寫 `limbs.torso.position.y = 1.7`（第 1475 行），idle 分支只改 `scale.y` 不改 `position.y` | 站著與走路是兩個不同的身體：走路時軀幹瞬間下墜 0.33，肩線出現空洞。實拍「肩是浮球」有一半是這個造成的 |
| **3** | **沒有任何關節球** | 肩 pivot 在 `x=0.42, y=2.36`，肩甲球在 `x=0.38, y=2.42`，袖口頂在 `y=2.14` — 三件互不相接 | 手臂一擺就是硬斷層 |
| **4** | **所有大形都是徑向對稱的圓柱／圓錐** | 軀幹、裙、大小腿、手臂全是 Cylinder | 沒有正面／側面的形態差異，沒有褶，剪影是一根柱。這才是「唔精細」的根 |

**修法順序**：先修 1（一行 `srgb()` 工具，收益最大）→ 再修 2 → 再上 3、4。若時間只夠做一半，做 1 與 2。

### 三條通則（比逐條修正重要）

1. **外掛件半徑 > 被覆蓋件同高半徑 + 0.015。** 皮帶、領巾、袖口、腰頭都適用。段數越少餘量要越大（20 段再多留 0.004）。
2. **`CylinderGeometry` 的 θ=0 在 +z（正前）**，`x=r·sinθ, z=r·cosθ`。要方位角偏移就直接寫角度，**不要加 π/2**。
3. **任何「殼」貼到臉上之前，先算它在眼睛高度的前緣 z**，必須 < 頭骨同高 z − 0.015。球殼的危險區永遠是 θ≈85–95°（赤道略上方），不是頂點。

## 2. 逐部件幾何配方

### 2.0 先貼這三個工具函數（r128 沒有 BufferGeometryUtils，必須自己寫）

```js
/* 幾何合併：把多個幾何按矩陣烘進去，合成一個 BufferGeometry → 1 draw call */
function mergeGeos(items) {                 // items: [{g: Geometry, m?: Matrix4}]
  const gs = items.map(function (it) {
    const g = it.g.clone();
    if (it.m) g.applyMatrix4(it.m);
    return g.index ? g.toNonIndexed() : g;
  });
  let n = 0; gs.forEach(function (g) { n += g.attributes.position.count; });
  const pos = new Float32Array(n * 3), nor = new Float32Array(n * 3), uv = new Float32Array(n * 2);
  let o = 0;
  gs.forEach(function (g) {
    pos.set(g.attributes.position.array, o * 3);
    if (g.attributes.normal) nor.set(g.attributes.normal.array, o * 3);
    if (g.attributes.uv) uv.set(g.attributes.uv.array, o * 2);
    o += g.attributes.position.count;
  });
  const out = new THREE.BufferGeometry();
  out.setAttribute('position', new THREE.BufferAttribute(pos, 3));
  out.setAttribute('normal',   new THREE.BufferAttribute(nor, 3));
  out.setAttribute('uv',       new THREE.BufferAttribute(uv, 2));
  out.computeBoundingSphere();
  return out;
}

/* 位置／旋轉／縮放 → Matrix4 */
function M(x, y, z, rx, ry, rz, sx, sy, sz) {
  const q = new THREE.Quaternion().setFromEuler(new THREE.Euler(rx || 0, ry || 0, rz || 0));
  return new THREE.Matrix4().compose(
    new THREE.Vector3(x || 0, y || 0, z || 0), q,
    new THREE.Vector3(sx == null ? 1 : sx, sy == null ? (sx == null ? 1 : sx) : sy,
                      sz == null ? (sx == null ? 1 : sx) : sz));
}

/* Lathe 捷徑：[ [r,y], ... ] */
function lathe(pts, seg) {
  return new THREE.LatheGeometry(pts.map(function (p) { return new THREE.Vector2(p[0], p[1]); }), seg);
}

/* sRGB → 線性（★ 修 §0 問題 1 的唯一工具，只用在角色身上，不要動世界） */
function S(hex) { const c = new THREE.Color(hex); if (c.convertSRGBToLinear) c.convertSRGBToLinear(); return c.getHex(); }
```

> `toonMat(S(0x2E5C8A))` — 上屏就會是 `#2E5C8A`。**§6 的 hex 全部是「上屏目標色」，一律套 `S()`。**

### 2.7 裙（12 褶）

**這不是截頭圓錐。** 段數必須是褶數的 2 倍，讓「峰／谷」正好落在頂點上。

```js
const FOLDS = 12, SEG = FOLDS * 2;                     // 24
const skirt = new THREE.CylinderGeometry(0.215, 0.400, 0.44, SEG, 3, true);
const pos = skirt.attributes.position;
for (let i = 0; i < pos.count; i++) {
  const x = pos.getX(i), y = pos.getY(i), z = pos.getZ(i);
  const ang = Math.atan2(x, z);                        // 0 = 正前
  const t   = (0.22 - y) / 0.44;                       // 0 腰 → 1 擺
  const amp = 0.018 + 0.062 * t;                       // ★ 褶在腰處收斂、擺處最深
  const f   = 1 + amp * Math.cos(FOLDS * ang);
  pos.setXYZ(i, x * f, y + (t > 0.9 ? 0.014 * Math.cos(FOLDS * ang) : 0), z * f);
}
pos.needsUpdate = true;
skirt.computeVertexNormals();
skirt.applyMatrix4(new THREE.Matrix4().makeScale(1, 1, R.ZS_SKIRT));
```

- 位置：`(0, 1.34, 0)`（世界 1.12–1.56）
- 材質：`flatShading = true` ← **關鍵**。每片褶面法線不同，4 段 toon ramp 會自動把明暗交替打出來，不用貼圖、不用第二顆材質
- **裙內殼**：同幾何 `scale 0.985`、`material.side = THREE.BackSide`、顏色為裙色 ×0.55。沒有這個，從低角度看裙底是透空的
- **裙擺 trim**：`CylinderGeometry(0.404, 0.408, 0.035, SEG, 1, true)`，同一套褶位移（amp 固定 0.080），奶油色
- 腰頭：`CylinderGeometry(0.220, 0.222, 0.045, SEG, 1, true)` 於 y 1.545，外套主色

褶的視覺驗算：擺部 r 在 0.400 × (1 ± 0.080) = 0.368–0.432 之間擺動，峰谷差 0.064 世界單位 ≈ 8 px @8m。夠看。

### 3.1 頭骨（臉貼圖貼在同一顆球上，**不另做貼片**）

舊版用「額頭一片板」是最刺眼的問題。這裡改用 **UV 重映射**：把正前方 ±57° 的方位角映射到整張貼圖寬度，其餘方位被 `ClampToEdge` 壓成純膚色。結果是 **1 個 draw call、零接縫、臉部像素密度 4.5 px/度**。

```js
const FACE_HALF = THREE.MathUtils.degToRad(57);          // 0.9948 rad
const skullGeo = new THREE.SphereGeometry(0.330, 28, 22);
const uv = skullGeo.attributes.uv;
for (let i = 0; i < uv.count; i++) {
  const phi = uv.getX(i) * Math.PI * 2;                  // phi = π/2 為正前方 (+z)
  uv.setX(i, (phi - (Math.PI / 2 - FACE_HALF)) / (FACE_HALF * 2));
}
uv.needsUpdate = true;
skullGeo.scale(0.955, 1.0, 0.94);                        // → rx .315 / ry .330 / rz .310
```

- 位置：headGrp (0, 0, 0)（世界 2.730）
- 材質：`new THREE.MeshToonMaterial({ color: 0xffffff, map: faceTex, gradientMap: G3 })`
- 貼圖：`faceTex.encoding = THREE.sRGBEncoding` ★（漏了這行，臉會跟 §0 一樣被抬亮）
  `faceTex.wrapS = THREE.ClampToEdgeWrapping`、`anisotropy = 4`

> 若重映射太麻煩的退路：另做 `SphereGeometry(0.332, 20, 16, π/2−1.0, 2.0, 0.35, 2.35)` 臉部殼，UV 天然對應——但會有接縫風險，不建議。

**總則**：不要球殼。結構 = 底層體積（2 片部分球殼）+ **14 束刀片髮**（4 面錐體壓扁成刀狀）+ 馬尾 3 段。
刀片髮是本規格唯一能做出「剪影變化」的手段，長度必須**互不相同**。

```js
/* 刀片髮：4 面錐體壓扁 → 有中脊的刀狀，flatShading 後是典型日系髮束 */
function lock(len, w, thick, segs) {
  const g = new THREE.ConeGeometry(w, len, 4, segs || 2);
  g.applyMatrix4(new THREE.Matrix4().makeScale(1, 1, thick));  // thick ≈ 0.42
  return g;
}
```

六階以上、每階間距 ≥ 6%，去掉顏色仍能靠明度讀出結構。

**為什麼建議這組而不是沿用舊值**：舊值單看 hex 沒問題，但上屏後全部落在 60–85% 亮度的粉彩帶裡（實測 coat 從 0x2F5F96 抬到 #A9CDD8）。色相／比例不變，只把明度壓回設計值——世界觀不會跑掉，但角色會立刻「跳出來」。

> ⚠ `S()` 只解決「被 sRGB 二次抬亮」，`ACESFilmicToneMapping` 仍會再壓一點（約 −5~8% 亮度、高光偏暖）。落地後**務必做一次校色**：在角色旁放一顆 `toonMat(S(0x2E5C8A))` 的測試方塊，截圖取樣，若偏差 > 10% 就整體乘一個 `PALETTE_GAIN`（一個常數，別逐色硬改）。

## 7. 賽璐璐打光（不靠後處理）

現有 `TOON = toonGradient(4)` 是 `[0.25, 0.5, 0.75, 1.0]`——最暗階太黑，配合抬亮後就變泥。**角色另建 3 張 ramp，不要動世界的 TOON**：

```js
function gradTex(vals) {
  const n = vals.length, d = new Uint8Array(n * 4);
  vals.forEach(function (v, i) { const b = Math.round(v * 255); d[i*4]=d[i*4+1]=d[i*4+2]=b; d[i*4+3]=255; });
  const t = new THREE.DataTexture(d, n, 1, THREE.RGBAFormat);
  t.minFilter = t.magFilter = THREE.NearestFilter; t.generateMipmaps = false; t.needsUpdate = true;
  return t;
}
const G2 = gradTex([0.62, 1.00]);            // 硬：皮革、金屬、鞋底
const G3 = gradTex([0.52, 0.78, 1.00]);      // 布：外套、裙、領巾
const G4 = gradTex([0.46, 0.66, 0.84, 1.00]); // 柔：膚、髮、臉
```

| 手法 | 怎麼做 | 用在哪 |
|---|---|---|
| **階數分配** | 硬面 2 階、布料 3 階、有機 4 階 | 靴／腰帶／扣 → G2；外套／裙 → G3；頭／髮／臉 → G4 |
| **平面著色當褶** | `material.flatShading = true` | 裙、衣擺、靴翻邊。每片面法線不同 → ramp 自動打出明暗交替，**12 褶不靠貼圖就有立體感** |
| **內殼防透空** | 同幾何 `side: BackSide`、色 ×0.55 | 裙、衣擺。沒有後處理能做這件事 |
| **頭部描邊（選配）** | 頭骨幾何 `clone().scale(1.035)` + `MeshBasicMaterial({color:0x141018, side:BackSide})` | 只做頭（凸形，無 artifacts）。8m 處 ≈ 2.4px 線，正好 |
| **暗階不能純黑** | ramp 最暗階 ≥ 0.46 | 所有材質。純黑陰影會讓賽璐璐變成漫畫分鏡 |
| **前後臂分色** | 前臂用外套暗色 | 手臂沒有彎曲動畫，靠色階製造「兩段」 |

**不要做**：全角色 outline（非凸合併幾何沿法線外推會破線）、`MeshBasicMaterial` 臉部（不受光，太陽在背後時會假）。

## 8. 驗收標準（肉眼可判斷）

1. **剪影測試**：正面全部填黑，能數出「頭—頸—肩—腰—裙擺—靴」**六個**轉折點。
2. **灰度測試**：去色後，靴（最暗）／外套／裙（最亮）三層分明；圖縮到 50% 仍可辨。
3. **肩部連續**：手臂前擺 60°、後擺 40°，腋下與肩頂**都看不到洞或斷面**（肩球 r 0.135 ≥ 袖頂 0.112×1.15）。
4. **面部可讀**：截圖縮到 50%（模擬 8–10m），仍能認出「上眼線、虹膜、嘴」三樣。
5. **臉不歪**：眼睛在世界空間是 0.115 寬 × 0.125 高；貼圖無斜向拉伸、無接縫環。
6. **髮剪影**：側面看，額前有 **≥3 個不同高度的尖**，腦後有馬尾凸出；**不得出現連續球弧**。
7. **裙**：正面可見 ≥6 個褶的明暗交替；抬頭從下往上看，裙內側不是透空的黑洞。
8. **無穿插**：全身沒有任何硬邊穿出皮膚；髖、膝、肩、肘四個關節在最大擺幅下無接縫。
9. **靴**：側面看得到「鞋底—鞋身—翻邊」三段；鞋頭是圓弧不是方角。
10. **高度／效能**：`new THREE.Box3().setFromObject(player).max.y` ∈ [3.24, 3.28]；
    `renderer.info.render.calls` 增量 ≤ 45，`triangles` 增量 ≤ 12000。
11. **走路不跳**：站著與走路切換時，軀幹、肩線、裙的位置**完全一致**（驗 §0 問題 2）。
